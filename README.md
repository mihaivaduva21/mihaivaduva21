# Mihai Vaduva

**Security engineer. Founder of [SiegePal](https://siegepal.com)** — a San Diego based cybersecurity and AI engineering consultancy.

Most of my work sits on the unglamorous side of security: identity plumbing that holds up under audit, cloud controls that survive contact with production, and the automation that stops the same finding from coming back next quarter.

Before SiegePal I was a security software engineer at a Fortune 500 company, where I built multi-tenant IAM infrastructure, BYOK and column-level encryption, and FedRAMP/FIPS compliance controls across AWS, Azure and GCP.

---

## What I work on

**Identity and access** — IAM architecture, SSO, SCIM, MFA, RBAC, privileged access, secrets management

**Cloud security** — AWS, Azure and GCP; architecture review, control implementation, hardening

**Offensive security** — penetration testing across web applications, APIs, cloud environments and networks

**DevSecOps** — pipeline security, SAST/DAST/SCA, IaC scanning, automated security gates

**Compliance engineering** — SOC 2, HIPAA, PCI, ISO/IEC 27001 and ISO/IEC 42001 readiness, control implementation and evidence automation

**Incident response** — investigation, containment, forensics and post-incident remediation

**AI engineering** — production-grade agent and workflow systems that replace manual reporting, review and approval work
